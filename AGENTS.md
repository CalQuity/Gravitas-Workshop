# Workshop coding-agent rules

The notebook is the source of truth. Follow its current mission only.

- Read any project file when useful.
- Never read or print `.env` values.
- Only edit `student_work/retrieval.py` and `student_work/agent.py`.
- Do not modify tests, corpus files, infrastructure modules, scripts, or notebook JSON.
- Prefer explaining a small change before applying it.
- After editing, run only the focused check named by the notebook.
- Never use `git push`.

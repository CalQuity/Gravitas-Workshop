# Workshop concept illustrations

Three original generated concept scenes use the
[Ian Xiaohei illustration skill](https://github.com/helloianneo/ian-xiaohei-illustrations):

1. `01-skills.png`: a serious worker follows an unfolding manual, illustrating a reusable procedure.
2. `02-sandbox.png`: work happens inside a bounded dome, illustrating controlled execution. Its transparent background is intentional.
3. `03-evidence.png`: a worker stitches a claim to its source, illustrating citation provenance.

The illustrations intentionally contain no embedded text. English explanations
remain native and editable in Google Slides. The prompts request thin black
hand-drawn lines, white space, deadpan black characters, restrained orange and
blue accents, original physical metaphors, and no formal infographic or cute
mascot styling. Generated using the built-in image generation tool.

The generation prompts are recorded in `PROMPTS.md`.
